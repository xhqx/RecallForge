# RecallForge

Rust owns storage, validation, retrieval, CLI, and the MCP boundary. Keep modules cohesive.
SQLite is authoritative; Markdown is export and skill guidance. Runtime databases, model caches,
personal memories, credentials, and local machine configuration must never enter Git.
Use synthetic examples in tests and documentation. No hosted embedding service is required.
Run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo test`.
Run `python3 scripts/smoke.py` against the built binary for protocol/CLI verification.
The network/model-dependent semantic test is `cargo test --test semantic -- --ignored --nocapture`.

When this checkout is registered in RecallForge, use the recall skill before investigating
non-obvious failures and capture verified project lessons while context is fresh. Local capture
for this project is enabled. If the server is unavailable or the root is unregistered, continue
the development task and report any unsaved finding. Do not import global/personal memory.
